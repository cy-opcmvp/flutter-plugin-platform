## 产品与用户上下文（简短）

- **产品**：桌面优先（Windows 首发）的插件工具箱，Flutter / Material 3 基座，目标六端。内置插件：计算器、截图、世界时钟；支持 Python Sidecar 扩展。
- **用户**：中文优先的个人效率工具用户。两类典型画像：把工具箱当**生产力装备**（关心可用性状态、安装原因、密度）；把工具箱当**日常伙伴**（关心顺眼、顺手、低学习成本）。
- **核心三页**：
  1. **插件目录页**——插件卡片（名称/描述/版本/能力标签）+ 可用性徽章（可用 / 不可用 + 结构化原因）+ 启用状态；
  2. **插件详情页**——基本信息区、启用/停用开关、声明式设置表单（文本/数字/下拉/开关/开关组）、Sidecar 安装/卸载/启动/停止操作；
  3. **设置页**——界面风格选择（三 preset）、明暗模式（跟随系统/亮/暗）、语言（中/英）。
- **关键组件**：PluginCard、StatusBadge（不可用原因展示）、FormRenderer、ResultRenderer（文本/表格/图片/字段四类结果）、空状态、确认对话框。
- **硬约束**：所有令牌可映射到 Material 3 ColorScheme/TextTheme 角色；success/warning 不在 M3 ColorScheme 内，统一走 `ThemeExtension` 扩展（见 schema）；字体给出 Windows 桌面回退链；3 preset × 明暗 = 6 套主题。

## 统一令牌 schema 说明

三个方向**严格同构**，均按以下令牌树声明（F3-05 据此实现 `ThemeTokens` 抽象，三个 preset 各实现一份）。任何方向不得增加/删减令牌槽位，只能改变取值。

```text
color.primary / onPrimary / primaryContainer / onPrimaryContainer
color.secondary / onSecondary / secondaryContainer / onSecondaryContainer
color.tertiary / onTertiary / tertiaryContainer / onTertiaryContainer
color.success / onSuccess / successContainer / onSuccessContainer   → ThemeExtension<SemanticColors>
color.warning / onWarning / warningContainer / onWarningContainer   → ThemeExtension<SemanticColors>
color.error / onError / errorContainer / onErrorContainer
color.surface / surfaceContainerLowest / surfaceContainerLow / surfaceContainer
color.surfaceContainerHigh / surfaceContainerHighest / surfaceVariant
color.onSurface / onSurfaceVariant / outline / outlineVariant
color.inverseSurface / onInverseSurface / scrim / shadow
neutral.N0..N5                          // 6 级中性色阶（方向间必须真正不同）
type.family / type.familyMono           // 含 Windows 回退链
type.display / type.title / type.body / type.label   // {size, lineHeight, weight}
shape.radiusXs / radiusSm / radiusMd / radiusLg      // 4 档
shape.strokeHairline / strokeAccent / strokeFocus    // 3 档描边
space.1..7                               // 4pt 基间距阶梯
elevation.e0 / e1 / e2 / e3              // ≥3 档海拔
motion.durFast / durBase / durSlow       // ≥3 档时长
motion.curveEnter / curveExit            // 缓动
motion.canAnimate[ ] / neverAnimate[ ]   // 动效边界
```

**Material 3 映射规则（三方向通用）**：

| 令牌组 | M3 落点 |
|---|---|
| color.primary/secondary/tertiary/error 全家 | `ColorScheme` 同名角色 |
| color.surface 全家 + onSurface/outline 族 + inverse/scrim/shadow | `ColorScheme` 同名角色 |
| color.success/warning 全家 | `ThemeExtension<SemanticColors>`（M3 无此角色） |
| type.display → `headlineMedium`；type.title → `titleLarge`/`titleMedium`；type.body → `bodyMedium`/`bodyLarge`；type.label → `labelMedium`/`labelSmall` | `TextTheme`（preset 覆写字号/行高/字重） |
| shape.radius* | `ThemeData` 各组件 `shape` + 组件内圆角常量 |
| space.* / elevation.* / motion.* | 组件布局常量 + `AnimationDuration`/`Curve` 常量 |
| neutral.N0..N5 | 仅作语义背景层的推导来源，不直接暴露给组件 |

**对比度验收规则**：正文级前/背景对 ≥ 4.5:1（WCAG AA）；大字号/图标 ≥ 3:1。本文档每个方向色彩节列出已实测的关键对（数值为 WCAG 相对亮度公式实测值）。

**中性阶命名约定**：N0 → N5 一律从「最亮/最浅背景」排到「最深/最强前景文字」，暗色模式下 N0 是画布底、N5 是最亮文字——即中性阶的语义顺序固定，物理明暗随模式翻转。

## 方向 A：精密工具风（precision_tools）

### 1. 设计理念

为把工具箱当生产力装备的用户设计：他们一天打开十次，关心的是「哪个插件可用、为什么不可用、版本对不对」，而不是氛围。整体气质是**校准过的仪表台**——冷静的钢青蓝主色、蓝灰石墨中性阶、1px 描边构成的平面层级，读数（版本号/ID/原因码）一律等宽字体，像量具上的刻字。布局追求密度与扫读效率：紧凑行卡、右对齐元数据、极少装饰。明确不做的事：不做大圆角软糖感、不做氛围插画、不做任何让读数变慢的动画（无计数滚动、无弹性回弹）。

### 2. 色彩系统

**主色「钢青蓝」**（仪表面板蓝，克制、可信）；**次色「石墨蓝灰」**（金属框架，承载次要容器与文字）；**第三色「量规青」**（示波器/PASS 灯青绿，仅用于选中与强调点缀）。

### 3. 字体与字号阶

- **UI 字族（含 Windows 回退链）**：`'HarmonyOS Sans SC' → 'MiSans' → 'Microsoft YaHei UI' → 'PingFang SC' → sans-serif`
- **读数等宽字族（版本号/ID/原因码/尺寸标注专用，方向签名）**：`'Cascadia Mono' → 'Consolas' → 'Courier New' → monospace`
- **字号阶**：

| 级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| display | 28 / 36 | 600 | 页面主标题 |
| title | 18 / 26 | 600 | 区块/卡片标题（次级 title 15/22/500） |
| body | 14 / 22 | 400 | 正文/描述 |
| label | 12 / 16 | 500 | 标签/徽章/按钮；读数用等宽 12/16/400 |

- **中文场景字重建议**：正文一律 400；强调用 500；标题 600 封顶——雅黑系 Bold 在 14px 以下笔画发糊，禁止对正文使用 700+；等宽读数保持 400 并启用 tabular 数字。

### 4. 形状与密度

- **圆角阶梯（4 档）**：radiusXs **2**（刻度点/标签尾）、radiusSm **4**（徽章/输入框）、radiusMd **8**（卡片）、radiusLg **14**（对话框/面板）——整体偏锐利，无大圆角。
- **间距阶梯（4pt 基，7 档）**：4 / 8 / 12 / 16 / 24 / 32 / 48。密度高：卡片纵向内边距 12，列表行最小高 44，网格间距 16。
- **描边层级**：hairline **1px** `outlineVariant`（默认卡片与分隔线，描边优先于阴影）；accent **1.5px** `primary`（选中卡片/激活项）；focus **2px** `primary`（键盘焦点环）。
- **海拔层级**：E0 = 0 阴影 + 1px 描边（默认卡片）；E1 = `0 1 3 rgba(16,24,36,0.10)`（悬浮卡）；E2 = `0 4 12 rgba(16,24,36,0.14)`（菜单/Popover）；E3 = `0 8 24 rgba(16,24,36,0.18)`（对话框）。阴影冷色（蓝黑相），小而硬。

### 5. 动效原则

- **时长阶梯**：fast **80ms**（悬停/描边）、base **160ms**（开关/筛选重排）、slow **240ms**（面板展开）。
- **缓动**：进入 `cubic-bezier(0.05, 0.7, 0.1, 1)`（decelerate），退出 `cubic-bezier(0.3, 0, 0.8, 0.15)`（accelerate）。无弹簧、无过冲。
- **何物可动**：① 悬停描边与容器亮度变化（≤80ms，反馈像仪表指示灯）；② 筛选后列表项位移+淡入（≤160ms，≤24 项内启用）；③ 启用开关滑块位移 160ms。
- **何物禁动**：① 禁止读数类内容（版本、计数、状态码）做 tween/滚动计数动画——数字必须即时可信；② 禁止 spring/回弹、视差、背景装饰动画——工具不表演。
- 全局：`MediaQuery.disableAnimations` 时全部时长归零，仅保留透明度。

### 7. 组件风格要点

- **PluginCard**：1px 描边平面卡、无阴影；版本号右对齐等宽；选中态以 1.5px 主色描边 + 左缘刻度短线标示。
- **StatusBadge**：仪表读数式 4px 圆角小方徽章——状态点 + 双字短语；不可用时在卡内第二行以等宽原因码展开（如 `UNSUPPORTED_PLATFORM`）。
- **表单控件（FormRenderer）**：输入框 4px 圆角 + 1px 铅灰描边、标签固定上方（不浮动）；聚焦描边变 1.5px 主色，数字字段用等宽 tabular。
- **空状态**：极简——一条刻度标尺 + 单句说明 + 次级动作按钮，无插画。
- **确认对话框**：E3 白卡 14px 圆角，标题栏下 1px 分隔线；破坏性操作用故障红描边按钮而非填充。

## 方向 B：温暖生活风（warm_life）

### 1. 设计理念

为把工具箱当日常伙伴的用户设计：他们不背参数，打开工具箱像拉开家里的抽屉，希望一切顺眼、顺手、没有压迫感。气质是**陶与纸的日常器物**——柿橙主色像一枚陶土印章，米纸/亚麻中性阶带着纸张温度，卡片是 28px 大圆角的「便签纸卡」，浮在柔和的暖棕阴影上。层次靠阴影与留白而非描边，图标住进奶油色的圆泡泡里。明确不做的事：不做冷硬描边与等宽读数墙、不用高饱和大色块轰炸、错误提示不吼叫（不用刺眼纯红大横幅，用暖红柔和容器）。

### 2. 色彩系统

**主色「陶土柿」**（成熟柿子的暖橙红，亲和有食欲感）；**次色「茶褐」**（茶汤与胡桃木，承载次级容器）；**第三色「苔绿」**（盆栽苔藓，给全暖盘加入一点植物呼吸感）。

- **描边层级**：默认**无描边**，靠阴影分层；仅两处保留 hairline **1px** `outlineVariant`（输入框、列表分隔）；accent/focus 均为 **2px** `primary`（focus 为 2px 外扩环，柔和无发光）。

### 5. 动效原则

- **时长阶梯**：fast **120ms**（按压/悬停）、base **240ms**（卡片浮起/开关）、slow **400ms**（对话框/页面转场）。
- **缓动**：进入 `cubic-bezier(0.05, 0.7, 0.1, 1)`（decelerate，像放下茶杯的缓冲）；对话框 scale 0.96→1 + 淡入；开关允许 ≤5% 过冲（唯一允许的「弹性」）。
- **何物可动**：① 卡片悬停上浮 2px + 阴影加深（240ms，像拿起便签）；② 空状态插图轻呼吸（±1.5% 缩放、4s 循环，`disableAnimations` 时停止）；③ 启用开关的柔和过冲。
- **何物禁动**：① 表单校验错误禁止抖动/弹跳——错误容器 160ms 柔和淡入即可，生活感不等于闹腾；② 超过 6 项的列表禁止级联入场动画（等待感破坏「顺手」）；③ 正文文本禁止逐字/逐行动画。
- 全局：`MediaQuery.disableAnimations` 时全部时长归零，仅保留透明度。

## 方向 C：极简暗色专业风（dark_pro）

### 1. 设计理念

为把工具箱当「命令面板」的开发者用户设计：他们常驻暗色，希望界面像一台安静可靠的调试器——信息密度最高、对比最强、一切锐利利落，元数据（ID、版本、平台、原因码）用等宽字体直接亮出来，不藏姿态。色彩世界取自**编辑器语法高亮**：断点紫是主色（关键词），串值青是次色（类型），图线品红是第三色（git 图线条）——一套有出处的多重点缀，而非「黑底加一抹荧光绿」的俗套。深色是一等公民（先设计深色，亮色是由它推导的低饱和纸感图纸）；层级靠紫灰中性阶抬升 + 1px 描边，几乎不用阴影。明确不做的事：不做纯黑大底、不做呼吸/发光等装饰动画、不用大圆角和插画。

- **间距阶梯（4pt 基，7 档）**：4 / 8 / 12 / 16 / 20 / 28 / 40。密度最高：卡片纵向内边距 10–12，行间距 8，列表行最小高 40。
- **描边层级（暗色海拔的载体，地位高于阴影）**：hairline **1px** `#2B2840`（暗）/`#D9D6E7`（亮），几乎每个容器都有；accent **1px** `primary` + 左缘 **2px** gutter 状态线（方向签名）；focus **1px** `primary` 外加 1px 间隙描边（编辑器选区感，无光晕）。
- **海拔层级（暗色逻辑：tint 抬升为主，阴影为辅）**：E0 = 画布无框；E1 = surface + 1px 描边（卡片，无影）；E2 = `surfaceContainerHigh` + 描边 + `0 2 8 rgba(0,0,0,0.40)`（菜单/Popover）；E3 = scrim `rgba(8,7,13,0.60)` + 对话框 `surfaceContainerHigh` + 1px `outline` 描边 + `0 8 24 rgba(0,0,0,0.50)`。亮色变体改用紫灰阴影：E1 `0 1 2 rgba(20,18,29,0.06)`、E2 `0 4 10 rgba(20,18,29,0.10)`、E3 `0 10 24 rgba(20,18,29,0.16)`。

### 5. 动效原则

- **时长阶梯（全局最快）**：fast **60ms**（焦点/描边）、base **120ms**（状态点/悬停）、slow **200ms**（面板展开/结果渲染）。
- **缓动**：统一 sharp 曲线 `cubic-bezier(0.4, 0, 0.6, 1)`；退出用 linear-out-fast-in `cubic-bezier(0.4, 0, 1, 1)`。像终端刷新，不像视频转场。
- **何物可动**：① 键盘焦点环即时出现（≤60ms，等宽用户依赖焦点可预测）；② StatusBadge 状态点颜色切换 120ms；③ ResultRenderer 结果面板展开 200ms（高度 + 淡入，无弹跳）。
- **何物禁动**：① 禁止一切装饰动画——呼吸、浮动、视差、光晕脉冲一律不做；② 禁止阴影/海拔过渡动画——暗色层级用 tint 即时切换，过渡会产生「发光感」；③ 禁止光标闪烁、扫描线等「伪终端」装饰。
- 全局：`MediaQuery.disableAnimations` 时全部时长归零，仅保留透明度。

### 7. 组件风格要点

- **PluginCard**：6px 圆角行卡，左缘 2px gutter 线指示状态（可用=主紫/停用=灰/不可用=断言红）；ID 与版本等宽字体；hover 仅提亮描边不位移。
- **StatusBadge**：断点圆点 + 等宽状态码（`● ready` / `○ disabled` / `✕ e_platform`）；点击展开一行结构化原因明细（人话 + 码并排）。
- **表单控件（FormRenderer）**：4px 圆角 1px 描边输入框、方形复选与紧凑开关；键名等宽左对齐，聚焦为 1px 主色描边（无阴影光晕）。
- **空状态**：居中等宽提示块（如 `[ no plugins installed ]`）+ 一行灰字说明 + 主紫描边按钮——像一条安静的 REPL 输出。
- **确认对话框**：10px 圆角暗面板，1px 描边 + 60% 紫黑 scrim；确认为主紫填充、取消为描边按钮；危险操作按钮用断言红填充并二次确认。
