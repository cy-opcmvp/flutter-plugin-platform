## Exact configuration

Root `v2/pubspec.yaml`:

```yaml
name: plugin_platform_v2_workspace
publish_to: none
environment:
  sdk: ^3.10.0
workspace:
  - packages/plugin_contracts
  - packages/plugin_runtime
  - packages/plugin_devkit
```

Root analysis options must include `package:lints/recommended.yaml` and enable analyzer language settings `strict-casts`, `strict-inference`, and `strict-raw-types`.

Every package must use:

```yaml
publish_to: none
resolution: workspace
environment:
  sdk: ^3.10.0
```

Dependency rules:

- `plugin_contracts`: no runtime dependencies; dev dependencies `lints` and `test`.
- `plugin_runtime`: path dependency on `plugin_contracts`; dev dependencies `lints` and `test`.
- `plugin_devkit`: path dependencies on both `plugin_contracts` and `plugin_runtime`; dev dependencies `lints` and `test`.
- Choose current compatible stable constraints resolved by the installed Dart SDK; do not use `any`.
- Public library files remain intentionally empty except for a concise library documentation comment if analysis requires it.
- No Flutter, `dart:ffi`, `win32`, platform plugin, business plugin, or Sidecar code.
